assignment 1 for IR
Model
https://huggingface.co/uhygutfr/Swedish_BERT-based_L1_classifier 
The issue I intended to solve was to classify a writer’s l1, or first language, based on text written in Swedish. Because of the nature of the dataset used, the task was multilabel classification, rather than single. The data contained over 3000 sentences. The reason this task was selected was, in part, due to the convenience of the already found dataset, but also due to the possible real-world applications such a classifier could provide. For one, being able to identify information about a speaker can be very useful in something like forensic linguistics, such as identifying hackers based on demand letters, as has been a relevant issue of central discussion for Canvas, currently. A classifier like this could also be used in learning: for example, an education service teaching a language like Swedish, being able to identify a speaker’s native language can allow a system to offer specialised support for issues that might be more common for different l1 speakers. A person who speaks German may need help with grammar but less with word construction, while a person who speaks Mandarin may first need help with vocabulary. The model, in its current state, is quite terrible, as almost no fine tuning was done. Further, after training the model, it became clear that the dataset is heavily biased towards Arabic l1 writers, which further worsened model performance.
Dataset
https://huggingface.co/datasets/uhygutfr/Swedish_sentences_with_l1 
For the dataset of this assignment, a combined method of both natural data and synthetic data was used. The custom dataset was based on a subset of the Superlim dataset from AI Sweden , which included a Swedish sentence with a spelling error, as well as data on where the error was, a corrected sentence, and the writer’s l1, level of Swedish, and more. From this dataset, only the original sentences and corresponding writer l1 was taken. To supplement the data, 100 synthetic sentences were generated using codex to represent native Swedish writers, as no Swedish writers were in the original dataset. As many of the entries for l1 included multiple languages listed by the writer, the task became multilabel rather than single label. 
Demo

The demo was copied from the one given as an example and then modified using Codex. The sentences were randomly chosen from the dataset.
Evaluation
For this assignment, I used AI for generating the code of the model, generating the synthetic data, and to upload the model to huggingface. AI was also used to configure the app.py code from the example demo to my model. Uploading the dataset, minorly configuring the model’s hyperparameters, and coming up with ideas for the assignment was all done by me. Further, this report is written purely by me, a human, using only Word’s built-in spell check. 
	The AI tool used for this assignment was Codex, 5.5, with medium “intelligence”. This assignment was my first time properly using AI, as I feel using AI can easily trick one into believing they have learned and understood what the tool is doing, without knowing how to do it. It was somewhat enlightening to get hands-on experience with how a person may use AI to generate code, and how to work with this tool, especially in “steering” the LLM after the initial prompt. Overall, it is clear that AI can be almost annoyingly useful, especially for generating code. At times, it surprised me in catching things I did not mention in prompts, such as catching and “repairing” my previous attempt to convert a .py file into .ipynb to import the model into Google Colab when asking it to convert the model file. Although the fact that it “behaved” very human-like was somewhat unsettling, it did work well as a tool. That being said, I do not believe I will use it as much for future assignments as I have for this one. By having codex generate all code and orchestrating the upload, I feel I lost out on good experience with the model pipeline and architecture. Although it would not have been feasible to do this assignment without AI, I still feel limiting or completely excluding the use of AI is better in a learning environment, at least for myself.
